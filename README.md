# MealCircle 

A group food-ordering and delivery system for friends, classmates, roommates, or families who want to order food together.

##  Overview
Instead of every person placing a separate order, one person creates a MealCircle group and invites others. Each member selects their own food items, and the system combines everything into one group order — automatically splitting the bill.

##  How It Works
Create Group → Invite Members → Select Food → Combine Order → Split Bill → Place Order → Track Delivery

##  Main Users
- **Customer / Group Members** — select their own meals and pay their share
- **Restaurant** — receives and prepares the combined order
- **Delivery Rider** — delivers the group order
- **Admin** — manages users, restaurants, and system issues

##  Main Features
- Create a group food order
- Invite friends via a group code/link
- Each person selects their own food
- Automatic bill calculation per member
- One combined order sent to the restaurant
- Real-time order tracking
- Notifications for group members

## 💡 Problem It Solves
Normally, when a group of friends orders food, they place separate orders, split costs manually, and deal with multiple deliveries. MealCircle organizes everything into one combined, trackable order.
